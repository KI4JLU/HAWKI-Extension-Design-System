# Tokens

Two-tier model, per the styling contract decision record (KI-568, `docs/DESIGN_SYSTEM.md`):

- **Primitives** — raw `oklch()` scales, e.g. `--color-accent-100..900`. Never reference these
  directly from a component.
- **Semantic aliases** — `--color-interactive`, `--color-text`, `--color-focus-ring`, etc.
  Components reference semantic aliases only. `spacing`, `borders`, `radius`, `transitions` and
  `typography` are single-tier scales with no primitive/semantic split.

The table below is not hand-maintained — it reads whatever custom properties are actually
registered on `<html>` at render time, live, via `getComputedStyle`. There is nothing to keep in
sync by hand, and nothing to drift.
